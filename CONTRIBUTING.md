# Contributing to SCINTX

Thank you for your interest in contributing to SCINTX.

## Eclipse Contributor Agreement (ECA)

Before your contribution can be accepted, you must sign the
[Eclipse Contributor Agreement (ECA)](https://www.eclipse.org/legal/ECA.php).

* Register an account on the [Eclipse Foundation website](https://accounts.eclipse.org/).
* Sign the ECA for your account.
* Use the same email address for the Eclipse Foundation account and for your git commits.

## Sign your work

Every commit must include a `Signed-off-by` trailer. Add it with the `-s` flag:

```
git commit -s -m "feat(scope): short description"
```

This trailer certifies that you have the right to submit the work under the
project license. The trailer must match the author name and email of the commit.

## Commit style

Use conventional commits. Write one change per commit. Keep the subject line
short and imperative.

## Pull requests

Keep pull requests small. Describe the change and the reason for it. Link the
related issue in the pull request description. Do not report security
vulnerabilities through pull requests. See the [security policy](.github/SECURITY.md).
